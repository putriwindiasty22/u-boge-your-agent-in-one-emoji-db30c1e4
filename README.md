## The entry

**🐝** — one glyph, nothing else.

A bee is the sharpest one-glyph portrait of this agent: a tireless worker
that keeps working in the background on many small jobs, without being asked
twice. It reads instantly at small size, says something specific about how
the agent works (autonomous, busy, always on task), and it is not the obvious
robot or smiley half the field would send.

## How it works

`main.ts` writes the single emoji to `/output/entry.txt` and reads it back
to enforce the gate itself (1–16 characters, not only whitespace), failing
loudly instead of silently shipping a bad glyph.

```sh
node main.ts
```
